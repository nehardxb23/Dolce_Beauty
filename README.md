# 💄 Dolce Beauty

> **Beauty delivered as fast as pizza.**

Dolce Beauty is a premium Gen Z beauty e-commerce platform that reimagines online beauty shopping with **10-minute makeup delivery**, pizza-inspired packaging, and a sleek, modern shopping experience.

---

## ✨ Inspiration

Traditional beauty delivery takes days. Dolce Beauty changes that by combining the speed of food delivery with the excitement of beauty shopping. Every order arrives in iconic pizza-themed packaging, making every delivery feel like opening your favorite pizza box—except it's filled with beauty products.

---

## 🚀 Features

- 💄 less then 45-minute makeup delivery
- 🍕 Unique pizza-themed packaging
- 🛍️ Premium beauty product catalog
- ❤️ Wishlist functionality
- 🛒 Shopping cart
- 💳 Secure checkout
- 👤 User authentication
- 📦 Order tracking
- 🤖 AI-powered beauty assistant
- 📱 Fully responsive design
- ✨ Glassmorphism UI

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Replit Authentication
